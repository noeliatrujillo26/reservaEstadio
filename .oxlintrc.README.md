# Por qué `react/rules-of-hooks` está en "off"

La regla identifica los componentes de React por su **mayúscula inicial**. Este
proyecto escribe todo el JavaScript/JSX en minúsculas por convención, así que la
regla marcaba como error cada `useState`/`useEffect` de cada componente y de cada
provider: 52 errores, todos falsos.

No hay riesgo en ejecución. React decide qué es un componente por **cómo se usa**
(`<Navbar />`), no por cómo se declara: los archivos declaran `function navbar()`
y quien los importa les pone el alias con mayúscula. El build de producción, el
render server-side y el servidor de desarrollo lo confirman.

Se apagó porque un linter que sólo produce ruido deja de servir para encontrar
errores reales. El resto de reglas sigue activo.
